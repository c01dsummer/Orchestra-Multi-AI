# 跨角色交接

交接时先现查任务与产出状态，再提供完整记录。接手角色核对任务编号、版本、自检证据与作者运行是否一致；缺项则回补后继续。

```text
任务编号：DEMO-1
查询时间：带时区的当前时间
当前状态：执行中 / 待复审 / 有阻断项 / 待批准 / 已合并 / 已同步
需求与验收条件：本次处理范围和完成标准
产出物位置：相对路径或不含凭证的链接
待审版本：提交标识或明确的改动版本
作者运行：逐次列出实际引擎、实际模型、运行结果，失败的也保留
复审运行：实际引擎、实际模型、分级结论及覆盖版本
自检与证据：命令、结果、未验证范围
阻塞与待决事项：原因、选项、需要谁确认
下一步：接手角色、承担者及具体动作
配置版本：配置改动记录中的版本；另记规则表格式版本
```

没有调用模型时写「未调用」及原因，不编造模型名称。多家引擎参与编写时保留完整作者集合，不因删除产出或一次运行失败而缩小集合。通知组件的完成事件不能代替交接、自检或质量结论。
